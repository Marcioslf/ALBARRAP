# 👕 ALBARRAP Camisetas — E-commerce & Landing Page

> E-commerce modern, minimalista e de alta conversão para a **ALBARRAP Camisetas** (@camisetas_albarrap) em Vilhena – RO.
> Confecção própria de camisetas personalizadas, linha Oversized Boxy e atendimento integrado ao WhatsApp Direct para atacado e varejo.

---

## 🎨 Identidade Visual & Design System

- **Tema**: Deep Dark Navy (`#0A192F`) & Ivory Cream (`#FDFBF7`) com acentos em Amber Gold (`#F59E0B`) e Emerald Green (`#10B981`).
- **Tipografia**: `Outfit` & `Urbanist` (Headlines com geometria moderna arredondada) e `Plus Jakarta Sans` (Corpo fluido e legível).
- **Hero Stage 100vh**: Banner full-bleed com iluminação reflexiva nos títulos (`.text-shimmer-white` e `.text-shimmer-amber`), modelos em generative fill e 2 botões diretos de ação sem poluição de preços.
- **Interatividade & Animações**:
  - Menu Flutuante Glass Pill com alternância automática topo/rodapé ao rolar a página.
  - Provador & Personalizador de Peças com simulador de tamanho por altura/peso e seleção dinâmica de cores/tamanhos.
  - Animações Framer Motion de scroll reveal em todas as dobras do site.
  - Integração instantânea com WhatsApp Direct preenchendo automaticamente pedido, produto, cor, tamanho e dados do cliente.

---

## 🚀 Tecnologias Utilizadas

- **React 19**
- **Vite 6**
- **Tailwind CSS & Glassmorphism Design Tokens**
- **Framer Motion 12**
- **Lucide React Icons**

## 💻 Como Rodar o Projeto

```bash
# Instalar as dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
